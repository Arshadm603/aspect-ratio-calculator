# Aspect Ratio & Image Dimension Calculator

A fast, lightweight, mobile-first **Aspect Ratio and Image Dimension Calculator** built with pure HTML, CSS, and vanilla JavaScript. Designed specifically for content creators, video editors, and designers to instantly calculate missing image or video widths and heights without distorting proportions.

## ✨ Features
* **Instant Calculations:** Automatically compute missing dimensions as you type.
* **Quick Presets:** One-tap preset buttons for popular social media layouts:
  * **16:9** (YouTube / Widescreen HD)
  * **9:16** (TikTok / Instagram Reels / YouTube Shorts)
  * **1:1** (Square feed posts & avatars)
  * **4:5** (Instagram portrait posts)
  * **4:3** (Standard / Legacy format)
* **Mobile-First UX:** Fully responsive design optimized for seamless mobile browser use.
* **Client-Side Processing:** All calculations happen locally in the browser—no images or data are uploaded to external servers.
* **SEO & Ad-Ready:** Includes built-in Schema.org JSON-LD markup and optimized contextual text sections for high Google search ranking and AdSense integration.
