# Aspect Ratio & Image Dimension Calculator

A free, self-contained, browser-based calculator for finding image and video dimensions from a preset or custom aspect ratio. Enter a width or height and the matching dimension is calculated instantly.

The whole app lives in `index.html` — no build step, libraries, or external assets.

## Features

- Presets for 16:9, 9:16, 4:3, 1:1 and 4:5
- Custom ratios (e.g. 3:2, 2.35:1)
- Calculates height from width or width from height, rounded to whole pixels

## Run locally

Open `index.html` in any browser.
